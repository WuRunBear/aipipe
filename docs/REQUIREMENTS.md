# 原始需求

> 以下为用户最初提出的需求，忠实收录。

## 一、四大要点

1. **业务目标**：实现一个可自由定义的 AI 自动化任务流水线（如：下载视频 → 语音识别 → LLM翻译 → TTS配音 → 音视频合并，或图片批量标注等跨媒体非标任务）。
2. **拒绝节点画布**：放弃可视化的拖拽节点（Node/DAG 图），认为用画布描述复杂逻辑过于繁琐臃肿，希望**直接以纯代码形式**编写和编排逻辑。
3. **拒绝传统纯 Agent**：拒绝像 OpenClaw 这类基于纯自然语言驱动、执行不可控且容易产生幻觉或无限循环的自主 Agent。
4. **终极诉求（代码解释器范式）**：利用大模型的代码生成能力，让 AI **直接动态编写 Python 脚本**，并在安全隔离的沙箱（Code Interpreter）中执行、抓取报错、自动重试并跑通任务，同时要求该系统具有生产级的安全性与确定性。

## 二、一句话总结

> 你想搭建一个**"自然语言驱动 → AI 编写 Python 动态脚本 → 安全沙箱执行/自我纠错 → 固化为确定性任务"**的代码级 AI 工作流引擎。
